# Aveeva Herold Research Portfolio

A static, GitHub Pages-ready portfolio for Aveeva Herold. It has no build step and no dependencies to install.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `aveeva-herold`.
2. Upload the entire contents of this folder, preserving the `assets/` directory.
3. In the GitHub repository, open **Settings** → **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
5. Save. GitHub will publish the site at the Pages URL shown there within a few minutes.

## Before publishing

- Confirm the email address and LinkedIn link are still current.
- Replace `assets/documents/Aveeva_Herold_CV.pdf` whenever the CV is updated; retain the filename so the download button keeps working.
- All images and the CV are local assets, so the site works without third-party image hosting.

## Files

- `index.html` - page content and accessible structure
- `styles.css` - responsive visual design
- `script.js` - menu, lightbox, skills explorer, motion effects
- `assets/` - supplied photos and downloadable CV
